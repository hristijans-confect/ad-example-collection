How to prepare and connect your CSV

  1. Click Download sample CSV. Open it in Excel or import it into Google Sheets.
  2. Keep the header row unchanged: advertiser_name, advertiser_image_url, slide_number, ad_image_url, headline, subtext, cta_text, post_message, source_url, and extracted_at.
  3. Add one row per carousel image. Use the same advertiser_name for slides that belong to the same advertiser, and number slide_number in display order starting from 1.
  4. In Google Sheets, choose File → Share → Publish to web. Select the correct sheet tab, choose Comma-separated values (.csv), and click Publish.
  5. Copy the published URL, return to this tool, select Custom CSV URL, paste the link, and click Apply source.

Image and avatar URLs must be publicly accessible over HTTPS. A normal Google Sheets edit/share link will not work; use the published CSV link.
